# 《小女生：膠水貓大冒險》3D 沉浸式教育遊戲
> 依據國小國語三上第六課〈小女生〉（作者：鍾怡雯）量身打造，嚴格遵循 `edu_3d_game_workflow` 標準規範之 Web 3D 沉浸式互動教育遊戲。

線上體驗網址：[https://cc2025cindy.github.io/cat-game/](https://cc2025cindy.github.io/cat-game/)

---

## 🌟 遊戲架構與標準規範特色

1. **教材 4 幕 11 站 100% 原文對齊**：
   - 嚴格依照課本段落分為 4 幕、11 個站點（3 個劇情站 + 8 個關卡）：
     - **第一幕：初見膠水貓**（第 0 站〈緣起相遇〉、第 1 站〈緊跟的腳步〉、第 2 站〈形影不離〉）
     - **第二幕：呼喚與回應**（第 3 站〈清脆的呼喚〉、第 4 站〈一唱一和〉、第 5 站〈雪亮的大眼睛〉）
     - **第三幕：沙發上的溫馨時光**（第 6 站〈四腳朝天〉、第 7 站〈享受的模樣〉、第 8 站〈膝上的呢喃〉、第 9 站〈七嘴八舌整晚熱鬧〉）
     - **第四幕：永不結束的故事**（第 10 站〈永遠的家人〉）
   - 通過 `text_check.py` 驗證，全課 334 字 100% 逐字吻合課文原文。

2. **PIRLS 五層次提問與多樣題型**：
   - 24 道精美題目，完整涵蓋 PIRLS 五大認知層次：
     - 擷取訊息（6 題）、推論（5 題）、詮釋（7 題）、統整（4 題）、評鑑（2 題）
   - 混合 6 種互動題型：四選一 (`choice`)、是非題 (`tf`)、選詞克漏字 (`fill`)、詞義配對 (`match`)、順序排列 (`order`)、多選題 (`multi`)。
   - `choice` 題型 A–D 正解位置均勻分布（各恰占 25%），選項長度嚴格對稱。

3. **遊戲化機制與 1200×840 結業證書**：
   - **HP 體力條**：初始 100 HP，答錯扣血並觸發 `hurt()` 邊緣紅光抖動與課文線索提示。
   - **點心收集與稱號系統**：答對題目獲得小魚乾，通關後依比例頒授稱號（金牌貓咪守護者、溫馨陪伴好夥伴等）。
   - **高質感結業證書**：Canvas 即時生成 1200×840 PNG 證書，具備雙層金棕古雅框、稱號卡片、發證字號與朱紅大印（「小女生印」），支援一鍵下載。
   - **進度保存與自動解鎖**：通關後自動解鎖全關卡，並支援教師密碼 `ijun` 快速解鎖。

4. **行動端極致優化（手機與平板支援）**：
   - 左下角**圓形類比搖桿 (`#pad` / `#padKnob`)**：推滿前進速度達 3.5 m/s，推半速度等比縮小（類比搖桿），放開即刻回正並歸零停步。
   - 畫面單指滑動 360° 旋轉相機視角 (`P.yaw`)，雙指縮放視角距離。
   - `--appH` 動態適應視窗高度，直向（Portrait 375×812）與橫向（Landscape 812×375）均達成零捲動溢出（`scrollHeight <= innerHeight`）。

5. **視聽沉浸度與真實音效庫**：
   - **小主人真人語音**：整合 Google Drive 使用者錄製之 10 軌主人真人語音（呼喚、撫摸、聊天、餵食、稱讚等），標準化至 -16 LUFS。
   - **小女生貓咪聲音百寶箱**：30 款 YouTube 高清真實貓叫聲，涵蓋幼貓奶萌、委屈呼喚、討吃、沉穩大貓、雀躍打顫、戲劇長腔、呼嚕呢喃與清脆對答等 10 大情境。

## 🎮 操作指南

| 模式 | 控制方式 | 功能說明 |
| :--- | :--- | :--- |
| **電腦** | `W / A / S / D` 或方向鍵 | 角色移動（防穿透碰撞） |
| **電腦** | 滑鼠拖曳 / 滾輪 | 360° 旋轉視角 / 縮放鏡頭 |
| **電腦** | `Space` / `F` / `V` | 跳躍 / 坐上沙發 / 切換視角 |
| **手機** | 左下角虛擬搖桿 (`#pad`) | 類比推動行走（推越遠走越快） |
| **手機** | 畫面單指滑動 | 360° 自由環繞轉動視角 |
| **雙端** | 點擊提示菱形 (`◆`) | 與小女生互動並展開課文題目挑戰 |

## 🧪 自動化測試驗收結果

本遊戲已通過 `edu_3d_game_workflow` 全套 4 大自動化檢驗腳本：

1. **課文逐字對照檢查** (`text_check.py`):
   ```bash
   python scripts/text_check.py . --source 課文.txt --html index.html
   # 結果：通過（比對 11 站、來源 334 字 100% 逐字吻合）
   ```

2. **資料與品質檢查** (`quality_check.py`):
   ```bash
   python scripts/quality_check.py . --html index.html
   # 結果：通過（11 站、8 關卡、24 題、6 題型、A-D 各 25%、0 錯誤 0 警告）
   ```

3. **證書與解鎖檢查** (`cert_check.py`):
   ```bash
   python scripts/cert_check.py . --html index.html --save-key cat-game-v1 --cert-key cat-game-certs
   # 結果：通過（1200x840 PNG 生成、文字/稱號/朱印繪製、名字下載、localStorage 解鎖）
   ```

4. **行動裝置觸控搖桿檢查** (`touch_check.py`):
   ```bash
   python scripts/touch_check.py . --html index.html --station 7
   # 結果：通過（推滿 3.57m、推半 1.31m、放開歸零停步、直橫向 --appH 零溢出）
   ```
