# 《小女生：膠水貓大冒險》3D 沉浸式教育遊戲
> 依據國小國語三上第六課〈小女生〉（作者：鍾怡雯）量身打造之 Web 3D 沉浸式互動教育遊戲。

---

## 🌟 遊戲重大特色升級

1. **360° 空間自由視角與滾輪縮放**：
   * **滑鼠左鍵按住拖曳**（或手機/平板觸控滑動）：隨意 360 度環繞旋轉視角。
   * **滾輪滑動**（或雙指縮放）：流暢拉近/拉遠鏡頭，近距離欣賞貓咪與主人的細膩表情。

2. **實體家具碰撞防穿透系統**：
   * 人類與貓咪均配備實體圓柱碰撞體積，**不再穿透沙發、茶几、植物盆栽與牆面**，提供真實的碰撞阻擋與滑行手感。

3. **小主人坐上沙發功能**：
   * 靠近客廳大沙發，按下鍵盤 <kbd>F</kbd> 鍵（或點擊底部「坐上沙發」按鈕），主人會以優雅自然的坐姿坐在沙發座墊上。
   * 呼喚小女生時，貓咪會主動跳上來把前腳搭在主人大腿上（重現課本第三段插畫）。再次按 <kbd>F</kbd> 或方向鍵即可站起身。

4. **呼喚後近身多樣互動系統**：
   * 當主人與小女生靠近（小於 1.7 公尺）時，畫面頂部會自動彈出**近身互動浮動卡**：
     * **🪶 逗弄羽毛**：揮動彩色逗貓棒，小女生興奮抬爪跳躍撲抓！
     * **🖐️ 摸摸頭**：主人俯身撫摸貓頭與下巴，貓咪發出舒服呼嚕呼嚕聲。
     * **🐟 餵小魚乾**：消耗收集到的點心，貓咪大口咀嚼並冒出愛心，親密度與積分 +10！
     * **💬 一唱一和**：主人喊「小女生～」，貓咪以高低音調熱情回應。

5. **24 道精美題庫與點心收集獎勵系統**：
   * 擴充至 **5 大主題單元、共 24 道精選互動題目**（詞語探索篇、標點分號篇、成語狀況篇、生字部首篇、課文深究篇）。
   * 點擊右上角或底部的 **【📖 國語百寶箱】** 隨時開啟章節題庫闖關。
   * 每答對一題即可獲得 **🐟 脆脆小魚乾、🥫 特級貓罐頭、🥩 柔細肉泥條** 等點心，可用於 3D 世界中餵食小女生！

## 🎮 操作按鍵說明

| 操作 / 按鍵 | 功能說明 |
| :--- | :--- |
| **W / A / S / D** 或 **方向鍵** | 在公寓內自由行走移動（支援碰撞防穿透） |
| **滑鼠按住拖曳** / **觸控滑動** | **360° 自由環繞旋轉視角** |
| **滑鼠滾輪** / **雙指縮放** | **拉近 / 拉遠鏡頭距離** |
| **Space 空白鍵** | 貓咪跳躍（可跳上沙發、茶几與窗台） |
| **F 鍵** | **主人坐上沙發 / 離開沙發** |
| **C 鍵** | 主人大叫「小女生——！」呼喚貓咪飛奔過來 |
| **M 鍵** | 貓咪發出高低抑揚的喵喵叫 |
| **B 鍵** | 貓咪四腳朝天躺平翻白肚子享受 |
| **E 鍵** | 觸發附近家具與環境語文標記 |
| **V 鍵** | 無縫切換「小女生（貓咪 30cm 視角）」與「暖心主人（人類 1.6m 視角）」 |

## 🚀 快速啟動

使用瀏覽器直接雙擊開啟 [index.html](file:///Users/cindytsao/Desktop/1026遊戲製作/index.html)，或在終端機執行：
```bash
python3 -m http.server 8000
```
並在瀏覽器造訪 `http://localhost:8000` 即可立即暢玩！
